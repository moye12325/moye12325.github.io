⚠️ 注意事项

  1. 强制推送要谨慎：使用 git push -f 前确保不会影响其他人
  2. 合并前先更新：合并分支前确保两个分支都是最新的
  3. 提交信息要规范：使用清晰的提交信息，建议遵循约定式提交
  4. 定期同步 develop：在功能分支开发时定期同步 develop 的更新
  5. 避免直接在 develop 开发：始终通过功能分支进行开发
